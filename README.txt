SAINT MARON CHURCH — DEMO WEBSITE
==================================

HOW TO RUN THE DEMO
1. Unzip this folder anywhere on your computer.
2. Double-click index.html — it opens in your web browser. No installation needed.
   (For the smoothest experience, Chrome or Edge recommended.)

WHAT TO SHOW THE PRIEST
1. Walk through the five tabs: Home, News, Bulletin, Contact, Donate.
2. Scroll to the footer and click "Parish Staff Sign-In" (or open admin.html).
3. Sign in with the demo passcode:  cedar
4. Post a news item (add a photo from the computer, add a button/link).
5. Open the News tab — the new post is at the top.
6. Upload any PDF as a bulletin, then open the Bulletin tab to see it.
7. Remove an item with one click, then use "Reset Demo Content" to restore.

NOTES
- All church details (Mass times, phone, email, pastor name) are placeholders
  and clearly marked. Real content drops in before launch.
- Demo changes are saved only in the browser you're using. The production
  version uses a real content management system with a secure login
  (strong password + two-step verification), so changes publish for everyone.
- The Donate buttons link to the Zeffy and Venmo homepages for now; the live
  site will link to the parish's own accounts. No payment data ever touches
  the website itself.
